# Auftakt

Ein kleines Notensatzprogramm als WebApp für den Musikunterricht, vor allem auf dem iPad.
Schüler.innen sehen, was sie hören, und hören, was sie schreiben.

**Online:** https://jonathan-1414.github.io/auftakt/

Alle Daten bleiben auf dem Gerät. Es gibt keinen Server und keine Konten.

## Entwicklung

```bash
npm install      # einmalig: Abhängigkeiten installieren
npm run dev      # Entwicklungsserver starten
npm test         # Tests ausführen
npm run build    # fertige Seite nach dist/ bauen
```
